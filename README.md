# Haven Link — Time Nexus

> Projeto de equipe desenvolvido para o **Gênio Digital iTwin 2024 Brasil**.

## Sobre o projeto

O Haven Link foi concebido como uma solução baseada em iTwin para centralizar informações de estoque e facilitar a gestão de recursos em diferentes setores.

A proposta utiliza uma câmera e recursos de inteligência artificial para interpretar o estoque e disponibilizar essas informações no ambiente iTwin.

## Status

Projeto realizado em 2024 e mantido neste repositório como registro do trabalho da equipe.

Este repositório documenta o **Haven Link do Time Nexus**. O nome “Nexus” também pode aparecer em projetos posteriores, mas eles não devem ser considerados continuação deste trabalho sem documentação explícita.
